# CAD assembly

`POLAR-CAD-Assembly.step` is the complete Polar Bear mechanical assembly supplied with this repository. At 111.5 MB it exceeds GitHub's normal 100 MB per-file limit, so it is uploaded as a GitHub release asset instead of being stored in Git history.

After downloading it, verify the file from this directory:

```bash
shasum -a 256 -c POLAR-CAD-Assembly.step.sha256
```

Expected SHA-256:

```text
1286297d5d498e5c2942e2cc3204cb27b53195d7c90050f3a19b49b6547cf177
```
